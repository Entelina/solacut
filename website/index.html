02 / ENGINEERING ARCHITECTURE

为真实剪辑台打造的硬核工程规格。

没有云端抽水、没有格式转码折损、没有塑料感自动化黑盒。从音轨滤波到时间线回迁，每一环都按影视后期与字幕组生产标准逐项验证。

  • SPEC 01

    三道零漏翻闭环

    先用本地 FTS5 RAG 注入原创游戏术语与反直译红线卡；再执行源语种感知硬质检，拦截未译英文、日语假名、韩语谚文、俄语西里尔残留及时间轴跳句黑洞；发现缺口自动触发手术刀级定点补翻。

    RAG 注入 残留扫描 定点补翻
  • SPEC 02

    6 语种暗房 NLE 与逐字稿剪辑

    默认 English 界面并支持中/英/日/韩/俄/西无刷新秒切。内建全片逐字稿搜词建片（Full Transcript）、±30s 原片上下文核查、Draft → Reviewed 审校门禁与 100 步撤销栈，零 AI 亦可当免费本地文本剪辑器。

    J K L 逐字稿搜词 ±30s 上下文 100 步撤销栈
  • SPEC 03

    人声带通 × OBS 章节 × 弹幕雷达

    告别只看音量的粗糙算法：300-3400Hz 人声带通滤除爆炸误报，原生提取 MP4/MKV 内嵌 OBS 章节标记，并支持导入 Twitch / B站 / YouTube 弹幕生成本地热力图与梗词峰值，精准锁定无声神操作与冷面反讽。

    OBS Chapters Chat Spikes 300-3400Hz FFT
  • SPEC 04

    秒出 FCPXML / Premiere XML 与无损直切

    默认 NLE XML 极速模式（< 1s 零转码）直出严格合规的 DaVinci FCPXML 1.10 双序列与 Premiere Pro XML（完整保留双轨立体声与全部 OBS 章节标记），同时支持长 GOP 字幕校准原画无损直切。

    FCPXML 1.10 Premiere XML Lossless Copy
  • SPEC 05

    纯本地 BYOK 零隐私上传

    几十 GB 的未公开直播录像与工程文件全程留在你的硬盘，零视频上传、零云端排队。支持本地 RTX 显卡离线 faster-whisper 与自带 API Key（DeepSeek / OpenAI 兼容端点）直连，成本完全透明。

    0 字节素材上传 本地 RTX Whisper BYOK 直连
  • SPEC 06

    商用无限制语料分级

    便携分发包严格内置 228,210 条仅含 MIT / CC BY / CC BY-SA 商用无限制许可的六语种平行语料与原创电竞术语库；个人研究还可在本地一键从 OPUS 官方镜像拉取扩展至 600,000 条全量口语索引。

    22.8 万商用内置 一键扩 60 万 SQLite FTS5
03 / PRECISION PIPELINE

四步闭环，把 4 小时录屏压缩成可交付高光工程。

每一步均带参数指纹感知断点续跑——改了术语表或调整翻译风格，无需重跑音频分析与语音转写，秒级复算下游产物。

  1. STEP 01 Audio + Chapters + Chat

    三轨信号探测与死寂标定

    自动提取 OBS 纯人声麦轨与内嵌章节标记，融合 300-3400Hz 带通、弹幕刷屏曲线与 >=15s 死寂空白标定，零 API 消耗先判场次密度。

    OUT → peaks + chapters + chat.db
  2. STEP 02 ASR + Transcript

    短句转写与逐字稿检索

    执行轻声响度归一化与敏感 Silero VAD 切句，支持离线 RTX Whisper 或云端 ASR，生成可全文检索、一键框选建片的完整逐字稿。

    OUT → transcript.json (Searchable)
  3. STEP 03 6×6 RAG + Context QA

    6×6 初译与人工审校护栏

    毫秒级召回六语种参考卡完成初译与零漏翻质检；在工作台展开 ±30s 原片上下文核对反讽，按 R 将片段确认标为 Reviewed。

    OUT → Draft → ✓ Reviewed
  4. STEP 04 FCPXML / Premiere / FFmpeg

    秒回主力非编或无损直切

    默认 < 1s 零转码直出 DaVinci FCPXML 1.10 与 Premiere XML 双序列时间线，或经 Only Reviewed 门禁输出原画无损与多语种字幕成片。

    OUT → FCPXML + XML + EDL + MP4
